from langchain.llms import OpenAI
from langchain.prompts import PromptTemplate
from langchain.chains import LLMChain
🔹 Imports LangChain components:
 
OpenAI: Interface to use GPT models from OpenAI.
 
PromptTemplate: Used to define reusable text prompts with variables.
 
LLMChain: A chain that takes a prompt and LLM to generate output.
 
🧩 Create a Prompt Template
python
Copy code
prompt = PromptTemplate.from_template("What is a good name for a company that makes {product}?")
This creates a template string where {product} is a placeholder.
 
The .from_template() method automatically extracts variable names from the {} curly braces.
 
You can later pass the actual value (like "sports shoes") when running the chain.
 
🧠 Define the LLM
python
Copy code
llm = OpenAI()
This initializes the OpenAI GPT model (usually text-davinci-003 by default unless specified).
 
You can also set parameters like:
 
python

🔗 Create a Chain
python
Copy code
chain = LLMChain(prompt=prompt, llm=llm)
Combines the prompt and LLM.
 
The chain takes an input (product), fills it into the prompt, and sends it to GPT.
 
▶ Run the Chain
python
Copy code
print(chain.run("sports shoes"))
Internally, this substitutes the template:

🔄 Other Ways to Define a Prompt in LangChain
Besides from_template, LangChain allows multiple ways to define prompts.
 
✅ 1. PromptTemplate.from_template() ✅ (You already used this)
python
Copy code
PromptTemplate.from_template("What is a good name for a company that makes {product}?")
Easiest method. It automatically detects input variables.
 
✅ 2. Use PromptTemplate constructor directly
You can manually specify variables:
 
python
Copy code
PromptTemplate(
    input_variables=["product"],
    template="What is a good name for a company that makes {product}?"
)
✅ Same output as from_template, but more explicit.
 
✅ 3. Partial Prompt with default values
You can pre-fill some values in the prompt:
 
python
Copy code
prompt = PromptTemplate(
    input_variables=["product", "market"],
    template="Suggest a name for a {market} company that makes {product}."
)
 
partial_prompt = prompt.partial(market="sports")
print(partial_prompt.format(product="shoes"))
# Output: Suggest a name for a sports company that makes shoes.
✅ 4. Using f-strings (outside LangChain)
This is not a LangChain method, but just standard Python:
 
python
Copy code
product = "sports shoes"
prompt = f"What is a good name for a company that makes {product}?"
🔸 You can still pass this to LangChain using:
 
python
Copy code
PromptTemplate.from_template(prompt)
✅ 5. Custom Prompt Classes (advanced use cases)
You can define custom prompt templates by extending the base Prompt class, but this is only needed for very advanced or dynamic behavior.
