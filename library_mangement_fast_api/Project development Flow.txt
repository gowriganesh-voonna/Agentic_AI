Project Structure

library_cli/
├── main.py                # CLI entry point
├── data/
│   ├── books.json         # Stores book records
│   ├── students.json      # Stores student records
│   └── issued.json        # Tracks issued books
├── modules/
│   ├── book_manager.py    # Add/Update/Delete/Search books
│   ├── student_manager.py # Add/Update/Delete/Search students
│   ├── issue_manager.py   # Issue and return books
│   └── report_manager.py  # Generate reports
├── utils/
│   ├── decorators.py      # Decorators for logging and error handling
│   └── logger.py          # Logging setup
└── requirements.txt       # Optional, for dependencies if any
